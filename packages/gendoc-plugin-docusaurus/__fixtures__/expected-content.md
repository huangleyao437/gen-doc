# Installation

Follow these steps to install the library.

## Prerequisites

- Node.js 18+
- pnpm

## Install

```bash
pnpm add my-lib
```

Then import it:

```js
import { MyLib } from 'my-lib';
const  app =  initApp();
app.start();
```

## Supported Browsers

| Browser | Version | Notes |
| --- | --- | --- |
| Chrome | 90+ | Recommended |
| Firefox | 88+ | Full support |
| Safari | 14+ | Partial support |
